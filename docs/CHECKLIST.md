# 実機確認チェックリスト

GUI と Windows 固有の動作は CI では確認できていない。PC で以下を確認する。

## 起動・常駐
- [ ] exe をダブルクリックで起動できる（SmartScreen は「詳細情報」→「実行」）
- [ ] タスクトレイにアイコンが出る。左クリックでウィンドウが出る
- [ ] × ボタンで閉じるとトレイに格納される（初回だけバルーンが出る）
- [ ] トレイ右クリック →「終了」でプロセスが消える（タスクマネージャーで確認）
- [ ] 起動中にもう一度 exe を実行すると、2 つ目は起動せず既存のウィンドウが前に出る
- [ ] 常駐時のメモリ（タスクマネージャーの「メモリ」列）を記録: ____ MB

## ホットキー
- [ ] 別のアプリを前面にした状態で `Ctrl+Alt+P` → ウィンドウが前面に出て、検索欄にカーソルがある
- [ ] 設定でホットキーを変更 → 新しい組み合わせで動き、古い組み合わせでは反応しない
- [ ] アプリを再起動しても変更したホットキーが有効

## 自動起動
- [ ] 設定で自動起動をオン → `regedit` で `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\ProjectLauncher` に exe パス + `--tray` が入っている
- [ ] PC を再起動（またはサインアウト→サインイン）するとトレイに常駐している（ウィンドウは出ない）
- [ ] オフにするとレジストリの値が消える

## 登録
- [ ] フォルダをウィンドウにドラッグ＆ドロップで登録できる（複数同時も）
- [ ] 同じフォルダをもう一度落としても二重登録されない
- [ ] 「親フォルダをスキャン」で、Unity / Three.js / Windows ツールのフォルダが候補に出る
- [ ] Unity プロジェクトで Library を走査して固まらない（スキャン・状態更新ともに数秒以内）
- [ ] チェックを外したものは登録されない。登録済みのものはグレーで選べない
- [ ] 編集ダイアログで名前・種別・URL・タグ・メモを変えて保存 → 再起動しても残っている

## 一覧・Git 表示
- [ ] 未コミットがあるプロジェクトがオレンジで「未コミット N件」、件数が `git status --porcelain` の行数と一致
- [ ] ブランチ名が正しい
- [ ] .git のないフォルダは「Git未管理」（グレー）
- [ ] 最終更新日時が、Git ありは最終コミット日時、Git なしはファイルの更新日時になっている
- [ ] 登録済みフォルダを名前変更（または削除）→ 再スキャンで赤字「見つかりません」と 🗑 ボタンが出て、削除できる
- [ ] 検索（名前・タグ・メモ）、並び替え 3 種、「未コミットありだけ」が動く
- [ ] 20 件以上登録した状態で再スキャン中も、スクロール・検索が固まらない
- [ ] 2 回目以降の起動で、前回の状態が即表示されてから更新される

## ボタン
- [ ] 📁 エクスプローラーでそのフォルダが開く
- [ ] 💻 VS Code で開く（VS Code を PATH から外した / 入れていない環境では、ボタンがグレーでツールチップに理由）
- [ ] 🐙 HTTPS の remote と SSH（`git@github.com:...`）の remote の両方で、正しいリポジトリのページが開く
- [ ] 🌐 公開 URL を登録したときだけボタンが出て、ブラウザで開く
- [ ] ⌨ Windows Terminal がそのフォルダで開く（なければ cmd）
- [ ] 🎮 Unity プロジェクトで、対応するバージョンの Unity エディタが起動する（ない場合は Unity Hub が起動する）

## 異常系
- [ ] Git をアンインストール（または PATH から外して）起動 → 落ちずに「git未検出」と表示される
- [ ] `%APPDATA%\ProjectLauncher\projects.json` を壊して（中身を `{{{` にして）起動 → 空の状態で起動し、`.bak` が残る
- [ ] `%APPDATA%\ProjectLauncher\logs\` にログが出ている

## 表示
- [ ] 125% / 150% スケーリングで文字やボタンが崩れない
- [ ] 絵文字アイコン（📁💻🐙🌐⌨🎮🗑）が表示される（豆腐 □ にならない）
